# THE TREND TOWN — website starter

This is a responsive storefront prototype for THE TREND TOWN.

## Included
- Home, All Products, Contact Us pages
- Red/black/white streetwear styling
- Desktop left sidebar; mobile bottom navigation
- Category photo tiles, search, four-column desktop product grid
- Product cards show photos, names and short descriptions only — no prices, sizes or stock labels
- WhatsApp product enquiry buttons (product name only; asks customer to request price/availability)
- Contact numbers, Instagram, TikTok, delivery note and supplied Google Maps link
- Demo admin panel to add/edit/delete products and upload product photos

## Important before publishing
The admin panel in this starter is **demo-only**. It stores products and the login in the current browser's localStorage. That means:
- changes are visible only in that browser/device;
- the login is not secure enough for a public production website;
- clearing browser data can remove the demo products;
- uploaded images are stored in that browser and are not shared with visitors.

A real public store needs server-side authentication and a shared database/image store (for example, Supabase) before enabling public admin access. Do not publish this demo admin as a secure production login.

## Missing brand assets
The supplied circular red-and-white THE TREND TOWN logo has been cropped from the uploaded screenshot and added to the top navigation. The owner-photo section has been removed as requested.
